# Building a Financial Analytics Dashboard with Databricks

[Medium Article Link](https://medium.com/@nemekonen/stock-market-vs-fundamentals-building-a-financial-analytics-dashboard-with-databricks-5557c4c7e99e)

The goal of this project was to build a financial analytics dashboard by ingesting daily stock prices and financial data from multiple APIs and transforming the raw data into analytics-ready tables using Databricks and the Medallion Architecture. The dashboard provides a comprehensive view of a company's financial health, integrating stock performance, financial metrics, and sector-level comparisons to help identify potentially overvalued or undervalued companies.
